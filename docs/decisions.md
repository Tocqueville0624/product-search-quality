## 2026-09-26 — 本地 MVP 实施与冻结

- 用户明确授权本地实现、质量达标后的 GitHub 分享和中文技术 PDF；无需 AWS。原代码选择 MIT，公开数据保留 upstream Apache-2.0/NOTICE。
- Python 3.11.15 + Java 17.0.20.1 + Spark 3.5.7、local[4]；依赖固定。真实数据与两组官方 SHA-256 验证，不增加复制行。
- 官方 train/test 1 个 ID/规范化文本重合，从训练侧整组删除 3 行，保持官方 test。验证按 normalized query 的 seeded xxhash64 确定，未按行随机拆分。
- 训练前确定 17 个原生词汇特征、regParam 0.05、maxIter 100、tol 1e-6；比较无权重与逆频率权重两个候选，以 validation macro-F1 选模。
- 正式 test 前写入模型、数据分片、代码、配置哈希及曝光守卫；随后测试一次。独立审查确认顺序、哈希、官方测试成员一致。
